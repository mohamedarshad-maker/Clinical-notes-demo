# Demo Data Attribution

## ACI-Bench Dataset

If using the ACI-Bench dataset:

**Source**: https://github.com/wyim/aci-bench

**Citation**: Please cite the original ACI-Bench paper when using this dataset.

**License**: Refer to the ACI-Bench repository for the current license terms.

**Usage**: This demonstration project uses synthetic clinical notes from ACI-Bench for testing and evaluation purposes only.

## Synthetic Data

All sample patients and clinical notes in this PoC are synthetic and do not represent real individuals or medical records.

## Important Notice

**DO NOT use this system with real patient data (PHI) under the current architecture.**

This is a demonstration system only. It is not:
- HIPAA compliant
- Certified for clinical use
- Approved for production medical record processing
- Suitable for real patient data handling

For production use with actual patient data, a comprehensive security review, compliance certification, and architectural enhancements would be required.
